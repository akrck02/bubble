# 🧭 How it was built

This chapter is for someone who wants to learn from how Bubble came to be. It will tell, in the
author's words, how Bubble 3, a CSS framework of classes, became Bubble 4, a set of tokens made in
Go.

It is not written yet. Its chapters will follow the steps in the history, and each decision will be
the author's own: what was tried, what failed, what was chosen and why.

Until then, [core ideas](../3-core-ideas.md) explains the choices as they stand today.
